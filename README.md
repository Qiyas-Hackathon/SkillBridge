- Frontend: Angular         
- Backend: ASP.NET Core Web API         
- Database: EF Core with [ PostgreSQL]        
           
## How to Run Locally          
           
### Backend Setup          
           
1. cd backend          
2. dotnet restore          
3. dotnet ef database update            
4. dotnet run          
           
### Frontend Setup          
           
1. cd frontend          
2. npm install          
3. ng serve
